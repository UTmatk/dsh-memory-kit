# 长期记忆（你的名字 / 用户）

> 这是记忆主库，也是唯一真源。直接编辑这里，然后运行 `mem sync`（或让面板点「保存」）即可重建注入区。
> 每条格式：`- [YYYY-MM-DD] 一句话事实`。越短越好，一个事实一行。
> 不需要的整节可以删；注入预算约 24KB，超了会被截断。

## 偏好与习惯
